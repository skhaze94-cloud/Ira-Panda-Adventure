# The First Five Minutes · v0.12.0

A gentle opening sequence for Ara’s first woodland chapter: take a step, discover Ira’s pink ribbon, ask Pip about her trail, and celebrate a first lantern glow. Pip now connects the ribbon to Ira and points Ara toward Bramble and Moss.

The ribbon uses native vector drawing and existing character artwork. The discovery has a pickup reaction, sound and caption. One persistent guidance line tracks the current step. Movement, talking, glowing and exploration remain available throughout; visiting Pip first or glowing early cannot block progress. Completed steps survive checkpoints. Starting a new adventure clears them, while later chapters hide the coach.

Validation: automated real movement to the ribbon, Pip interaction, lantern success, checkpoint continuation, reset, later-chapter hiding and alternate action order; five-chapter smoke and quest/caption checks; storybook UI regressions; desktop and 740×360 native captures. This is an automated opening-flow check, not a timed novice-player study. GPU/phone frame rates remain unverified.
