# Ara the Panda: Quest to Find Ira — Godot v0.4

**Lantern Trails** is the current Godot edition on
`godot-4-v0.2-moonlight-depth`. The historical branch name is retained so
existing links continue to work. The browser edition is maintained on `main`.

This version includes all five quests and story interludes, distinct chapter
landscapes, smoother movement and camera following, obstacle-aware click
walking, and lantern exploration:

- Reveal hidden silver footprints toward quest locations.
- Wake glowing plants for hints, permanent light and a one-time heart reward.
- Shine from brass crescents to uncover shadow arrows and clues.
- Keep the original lantern reveals and bat-repelling ability.

## Play

Import `project.godot` in Godot 4.3 or newer with the Compatibility renderer,
wait for the PNG/audio imports, and press F5. Move with WASD / arrows or click
the ground, use Space to glow, E to interact, and Escape to pause.

See [README-GODOT.md](README-GODOT.md) for full controls, features, packaging
instructions, validation details and known testing limits. Local verification
used Godot 4.7.2; all five chapters passed quest, navigation and lantern checks.

The Unity 3D conversion has not started. This branch remains a native 2D Godot
project using the original painted artwork and music.
