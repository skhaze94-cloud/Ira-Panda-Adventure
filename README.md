# Ira Panda Adventure — Godot v0.9

**Object Upgrade Pack: Woodland Whimsy** brings twenty new storybook illustrations
to all five chapters: five bridge decks, five silly pumpkins, five signposts and
five friendly spooky displays. Forty-five little encounters decorate the secret
trails, with lantern reactions, animation and short captions.

All eleven crossings use illustrated timber, native rails, posts and hanging
bells. Puddlebrook's broken bridge still needs its driftwood quest; repairing it
reveals the new deck. Treasure hunts, the 400-point chapter crown and existing
quests continue to work with the earlier save format.

## Play in Godot

1. Extract the ZIP into a new folder.
2. Import `project.godot` in **Godot 4.3 or newer**, using Compatibility.
3. Let the editor import the PNG and audio files, then press **F5**.

Move with WASD/arrows, click/tap the ground, or use the paw stick. **Space / GLOW**
shines the lantern. **E / INTERACT** talks, opens chests, uses quest stations and
greets the new objects. Pumpkins offer **SAY BOO**; other displays offer **LOOK**.

Options include Music, Woodland Sounds, Gentler Motion and three graphics
presets. Continue remembers the current chapter's discoveries. A fresh chapter
starts its encounters again.
